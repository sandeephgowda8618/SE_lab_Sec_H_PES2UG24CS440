Helpdesk System Fix Report

Summary:
The original helpdesk system had multiple problems related to security, reliability, and code quality. I reviewed the issues reported by Bandit and Pylint, then corrected the script in helpdesk_system.py.

Main issues found:
- Hardcoded admin password in source code.
- Mutable default argument (audit_trail=[]), which can cause unintended data sharing across calls.
- Bare except block that silently swallowed errors.
- Unsafe subprocess usage using shell=True and an unvalidated hostname.
- Missing input validation for ticket data and file writing.
- Missing documentation and style problems such as long lines and naming inconsistencies.

What was implemented:
- Moved admin password handling to an environment variable instead of storing it directly in code.
- Replaced the mutable default with a safe None-based initialization.
- Added validation checks before assigning or updating ticket data.
- Replaced the shell-based ping call with a safer subprocess.run call using a direct argument list and hostname validation.
- Added safe file writing with explicit encoding.
- Encapsulated ticket logic in a TicketManager class to improve structure and reduce global-state issues.
- Added module and function docstrings, cleaned up naming conventions, and removed unused variables to improve maintainability.
- Kept the original code as a commented reference block at the top of the file, as requested.

Result:
The corrected script now runs cleanly, passes Python syntax validation, and receives a high Pylint score with no reported issues.
